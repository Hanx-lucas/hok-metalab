# 技能与开源参考

本次使用 Codex 已安装的 Data Analytics 技能组织数据审计、分析、图表、交互应用与报告，并使用 PDF 技能进行页面渲染和逐页验收。共享 Data 应用运行时提供页面壳、图表编辑、来源查看、权限与导出；本项目主要实现 Python 管线、指标与验证、页面内容及视觉设计，不能将共享基础设施描述为从零研发。

## 高星 GitHub 技能

阅读并应用 [Anthropic skills 的 frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)：强调清晰的设计方向、克制的色彩、排版、响应式和可访问交互。仓库热度通过 GitHub API 实际核对；记录在 `research/frontend_skill_repo.json`，这是采集时快照，星数会变化。

技能内容快照在 `research/frontend_design_skill.txt`，原许可证保存在 `research/frontend_design_license.txt`。遵循其设计指导构建古金、墨绿与暗色峡谷视觉、真实英雄头像、英雄观察面板、桌面/手机布局；没有下载执行不明仓库脚本，没有替换共享运行时。

## 数据来源与接口发现

- [腾讯官方赛事目录](https://prod.comp.smoba.qq.com/leaguesite/leagues/open)：获取实际赛事ID和日期。
- [腾讯官方赛事英雄汇总](https://prod.comp.smoba.qq.com/leaguesite/league/hero/settle_list/open?league_id=20260003)：所有职业数据直接请求此官方域名；保留原始响应、时间、hash。
- [腾讯官方英雄目录](https://pvp.qq.com/web201605/js/herolist.json)：当前英雄名、ID、推荐分路和职业标签。
- [leirong/wzry-database-server](https://github.com/leirong/wzry-database-server)：只作为发现公开接口的代码线索；本项目没有复制其数据冒充直接采集，也没有运行其服务。
- [营地接口第三方文档](https://github.com/dxawdc/honor-of-kings-companion-api)：仅用来实现待验证的授权适配器。未取得登录会话，未声称完成日常分段采集。

## 其他依赖

Python分析使用Pandas、NumPy、SciPy、scikit-learn、openpyxl；图表/PDF使用Matplotlib和ReportLab。网页公共运行时使用React与Recharts。依赖版本写入`requirements-lock.txt`及应用的官方锁文件；各库按自身许可证使用，未更改许可声明。网页截图由Playwright控制新建的本地Edge测试实例，PDF由Poppler渲染检查。

公开发布前应保留参考与归属文档。原项目手工数据属于用户提供，来源限定为未独立核验的历史探索。网页使用腾讯官网公开英雄头像及赵云·苍天翔龙原画，经过尺寸和WebP优化后本地打包，版权归腾讯《王者荣耀》。来源URL、抓取时间和SHA-256记录在英雄美术清单；五路图标为本项目自行绘制的SVG。


## 英雄美术来源

133位目录英雄头像来自腾讯公开CDN `game.gtimg.cn`；赵云原画链接从其官方英雄详情页提取。美术仅用于非商业数据分析作品集展示，不属于本项目原创素材。来源记录见 `site/src/content/assets/hero-art/manifest.json`，发布网页的下载区保留 `hero_art_manifest.json`。
