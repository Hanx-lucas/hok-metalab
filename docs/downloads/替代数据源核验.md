# 日常分段替代数据源核验

核验日期：2026-10-11。目标是寻找中国大陆《王者荣耀》的英雄胜率、出场率、禁用率和分段历史，避免把个人战绩、战力榜、国际服或赛事数据误当成全服日常统计。

## 结论与可用来源

**苏苏助手数据站可以补充日常分析，本次已取得匿名公开样本。** 提供者网页可以切换全分段、巅峰赛1350+、顶端排位、巅峰千强；接口实际成功返回，而非仅凭搜索摘要判断。它是第三方整理的真实公开记录，未与王者营地独立对账，不标成腾讯官方直采。

## 本次真正取得的覆盖

- 当前榜单：公告日标签2026-10-10，538条来源条目×分段，485条三指标完整。巅峰千强133条，其余三档各135条。来源包含元流之子形态、李信玩法变体，不能声称135个官方独立英雄。
- 历史试采：赵云、关羽、鲁班大师、蒙恬，共39,344条英雄×分段×日期记录，其中33,805条三指标完整。最早2019-09-28，最近2026-10-10；这不是全英雄的历史覆盖。
- 鲁班大师2020-09-24有一条完全相同的重复日记录，仅去重这一条，原始响应保留。
- 日期断档以及早期缺失指标都保留，不能补0。全分段的可用历史始于2021-03-03，顶端排位始于2021-12-19；不同分段起始时间不一致。详情见 `daily_coverage.csv`。
- 比较四英雄×四档共16组当前榜单与历史末日，12组存在指标或缺失状态差异，巅峰千强4组一致。原因可能是更新时间或统计窗口，但尚未核实；两套数据分开存储，不混合、平均或互相填补。差异见 `daily_reconciliation.csv`。

## 参数、单位与分析边界

提供者文档：[英雄排行](https://xug887phix.apifox.cn/api-429517673)、[历史记录](https://xug887phix.apifox.cn/api-184881160)、[使用声明](https://docs.91m.top/%E5%A3%B0%E6%98%8E.html)。

当前榜单 `getRanking` 的 `did=0/3/4/5` 分别对应巅峰千强/顶端排位/1350+/全分段；`aid=0,bid=0,cid=0` 对应页面默认的英雄排行、全部大区昨日、全部分路。实测点击页面确认映射。

历史 `getHeroChartsLog` 使用 `aid=0,bid=0,id=英雄ID` 返回带分段前缀的全部历史列。不能套用榜单的did：试探did=3/4/5而bid=1时返回相同的巅峰千强历史，说明参数会被忽略。本项目只接收有分段列名的响应。

当前榜单 `allWinRate/allPickRate/allBPRate` 是百分点，需要除以100；历史指标已经是0–1比例。`allBanRate` 数组第二项对应页面展示的禁用率，第一项是双禁口径、可能超过100%，不能截断第一项冒充禁用率。

当前公告的daily只是来源页面日期标签，不能由采集时间冒充统计日期。接口没有每英雄场次、胜负计数、S赛季映射与完整采样规则。不能构造Beta区间、显著性结论、全服代表性保证，不能把每日公布指标平均成“赛季整体胜率”。日期曲线只能描述公布指标变化，不能单独证明版本调整的因果效果。来源长期分段定义是否发生变化也未核验。

提供者[声明](https://docs.91m.top/%E5%A3%B0%E6%98%8E.html)要求引用时注明出处，说明数据并非官方，部分功能需要登录，公开战绩屏蔽会影响统计。API响应还给出接入联系提示。本次是有限、低频的公开样本核验；后续更广泛或持续调用应遵循其接口接入规则，遇到登录限制停止，不绕过。

## 复现与作品集

默认离线重放已核验响应，不发网络请求：

```powershell
python scripts/prepare_daily_sources.py
python scripts/build_web.py
```

有限范围刷新：`python scripts/prepare_daily_sources.py --refresh`，共9次请求、每次间隔2秒，仅当前四档与4英雄历史；401/403或应用拒绝直接停止，不重试。扩大历史英雄范围前应核验提供者接入规则与完整覆盖，不能直接把试采结果写成全量采集。

主流水线 `python run.py --offline` 会读取独立原始目录并重建这些表。当前榜单、历史、覆盖审计、差异审计和来源元数据独立存储，不参与原KPL指数、时间回测或营地授权表。

交互作品集“日常与分段”新增四档胜率表、所选英雄同期分段对比及4英雄历史曲线；可切换指标/时间范围，查看来源并下载CSV。所有游戏S赛季标签仍需官方版本日历核验，不由年份猜测。

简历可以写“接入第三方公开日常分段数据，完成多源口径核验、缺失与重复处理、分段趋势展示”；现阶段不要写“取得全英雄历年排位逐局数据”或“官方全量分段模型”。
